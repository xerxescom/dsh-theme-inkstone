你
帮我看看这段配置为什么链接颜色这么淡。
助手

因为强调色在浅色背景上的对比度只有 3.9:1，低于正文的 4.5:1 下限。这套主题把链接抬到了 4.8:1，色相不变，只挪了亮度。

引用块的颜色也一并抬高了，否则引用里的链接会比正文更淡。

// 可读性优先：改色相，不改亮度层级
export function recolour(seed: string, hue: number) {
  const target = '4.5:1';
  return matchContrast(seed, hue, target);
}
